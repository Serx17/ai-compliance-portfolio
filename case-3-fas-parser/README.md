# Case 3: ИИ-Экран контроля лидогенерации (ФАС)

> Автоматизация проверки рекламных креативов на соответствие требованиям ФАС и банковским офферам.
> **Ключевой принцип:** LLM ищет семантические нарушения, код — формальные.

---

## Зачем это

МФО и банки работают через партнёрские сети и блогеров. Тысячи креативов ежедневно.

**Проблема:**
- Проверка одного креатива: **15–20 минут** вручную.
- Штрафы ФАС: **100 000 – 500 000 ₽** за нарушение.
- С 2026 года: реклама **без ERID** не учитывается для налога (п. 44 ст. 270 НК РФ).

**Решение:**
- Конвейер: **текст + изображение → отчёт о нарушениях за 5–10 секунд**.
- 7 зон контроля → **все нарушения найдены до публикации**.
- **HITL:** комплаенс-офицер подтверждает/отклоняет.

**Границы:**
- HITL — архитектурный принцип. Блокировка рекламы — **только человек**.
- Данные клиента **не покидают контур** (в production).

## Архитектура (кратко)

```
Креатив (текст + изображение)
        │
        ▼
┌─────────────────────────────┐
│ Препроцессор (Python)       │   ← OCR, нормализация
└──────────┬──────────────────┘
           │
           ▼
┌─────────────────────────────┐
│ LLM (YandexGPT / Qwen) + VLM│   ← Семантика + логотипы
└──────────┬──────────────────┘
           │
           ▼
┌─────────────────────────────┐
│ 7 ЗОН КОНТРОЛЯ              │   ← Python
│ 1. Гарантии доходности      │
│ 2. Указание ПСК             │
│ 3. Использование бренда     │
│ 4. Скрытые комиссии         │
│ 5. Маркировка ERID          │
│ 6. Запрещённые соцсети      │
│ 7. Русский язык             │
└──────────┬──────────────────┘
           │
           ▼
    HITL (комплаенс-офицер)
           │
           ▼
    Финальный отчёт (JSON / PDF)
```

## Ключевое архитектурное решение

**LLM ищет семантику. Код — формальные проверки.**

| Задача | Кто решает |
|---|---|
| Гарантии доходности | LLM |
| Указание ПСК | LLM + код |
| Использование бренда | VLM + LLM |
| Скрытые комиссии | LLM |
| Маркировка ERID | VLM + код |
| Запрещённые соцсети | Код |
| Русский язык | LLM + код |

**Почему так:** LLM ошибается в формальных проверках. Код — детерминирован. Юристу нужны бинарные ответы.

**Подробно:** [architecture.md](architecture.md), раздел 3 (trade-offs).
